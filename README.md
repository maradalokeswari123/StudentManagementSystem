# Student Management System

A Java console-based Student Management System built using JDBC and MySQL.

## Features

- Add Student
- View Students
- Search Student by ID
- Update Student
- Delete Student
- Menu-driven Console Application

## Technologies Used

- Java
- JDBC
- MySQL
- Git
- GitHub

## Project Structure

```
src/
 ├── app/
 ├── dao/
 ├── model/
 └── util/
```
